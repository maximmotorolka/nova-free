# Nova Free

Бесплатный клон чата [chat.novaapp.ai](https://chat.novaapp.ai) — **без Pro, без регистрации, без лимитов**.

- Один HTML-файл, без зависимостей
- Модель: GPT‑OSS 20B (openai‑fast) через бесплатный API [pollinations.ai](https://pollinations.ai)
- Стриминг ответов, история чатов в localStorage, выбор модели (Auto / Coder / Writer / RU)
- Markdown‑рендер, mobile-friendly
